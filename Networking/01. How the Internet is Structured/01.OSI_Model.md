# OSI Model

The OSI (Open Systems Interconnection) model is a conceptual framework that
breaks down how data travels between two computers into seven discrete layers.
Each layer has one job and hands its output to the layer above or below it.

Mnemonic (layer 7 → layer 1): **All People Seem To Need Data Processing**

---

## Layer 7 — Application

To enable communication between applications (such as web browsers or email
clients) and the underlying network, handling protocols for web browsing
(HTTP/HTTPS), file transfer (FTP), email (SMTP), and remote access (SSH).

- This is the only layer the end user directly interacts with.

---

## Layer 6 — Presentation

To translate data between the application and the network by handling
encryption (TLS/SSL), compression (GZIP), and character encoding (UTF-8),
ensuring both sides agree on how data is formatted.

- TLS/SSL is responsible for encrypting HTTPS requests so that anyone
  intercepting the traffic cannot read the contents.

---

## Layer 5 — Session

To establish, maintain, and terminate communication sessions between two
applications, managing the lifecycle of a conversation — for example, keeping
a login session alive across multiple requests.

- The TLS handshake occurs here, verifying the server's identity and
  negotiating an encryption key before any data is exchanged.

---

## Layer 4 — Transport ⭐

To provide reliable, end-to-end delivery of data between applications by
breaking data into segments, assigning port numbers to identify the target
application, and guaranteeing delivery and ordering using TCP, or providing
fast connectionless delivery using UDP.

- TCP breaks the HTTP request into numbered segments and guarantees delivery —
  if a segment is lost in transit, TCP requests a re-send.
- Port numbers identify which application on the destination machine should
  receive the data. Common ports: 443 (HTTPS), 80 (HTTP), 22 (SSH), 53 (DNS).

PDU name: **Segment**

---

## Layer 3 — Network ⭐

To handle logical addressing and routing across multiple networks, using IP
addresses to identify source and destination machines and forwarding packets
hop-by-hop toward their destination via routers.

- IP (Internet Protocol) wraps each TCP segment in a packet, adding the source
  and destination IP addresses.
- ICMP (Internet Control Message Protocol) also lives here — it is the protocol
  used by the `ping` command to test reachability.

PDU name: **Packet**

---

## Layer 2 — Data Link

To transfer data reliably between two directly connected devices on the same
network segment, using MAC addresses to identify hardware, with protocols such
as Ethernet and Wi-Fi managing access to the physical medium.

- ARP (Address Resolution Protocol) operates here — it is how a device
  discovers the MAC address of the next hop (e.g. your router) when it only
  knows the IP address.
- Switches operate at this layer; routers operate at layer 3.

PDU name: **Frame**

---

## Layer 1 — Physical

To transmit raw bits across a physical medium — converting frames into
electrical signals (copper cable), light pulses (fibre optic), or radio waves
(Wi-Fi) — governing voltage levels, frequencies, and connector types.

- No protocols operate here in the traditional sense.
- Devices at this layer include network interface cards (NICs), Ethernet cables,
  fibre optic cables, and wireless antennas.

PDU name: **Bit**

---

## PDU summary

| Layer | Name         | PDU     |
|-------|--------------|---------|
| 7     | Application  | Data    |
| 6     | Presentation | Data    |
| 5     | Session      | Data    |
| 4     | Transport    | Segment |
| 3     | Network      | Packet  |
| 2     | Data link    | Frame   |
| 1     | Physical     | Bit     |

---

## Key protocols by layer

| Layer | Protocols                        |
|-------|----------------------------------|
| 7     | HTTP, HTTPS, FTP, SMTP, SSH, DNS |
| 6     | TLS/SSL, GZIP, UTF-8             |
| 5     | TLS handshake, RPC               |
| 4     | TCP, UDP                         |
| 3     | IP, ICMP, OSPF, BGP              |
| 2     | Ethernet, Wi-Fi (802.11), ARP    |
| 1     | (hardware only — NIC, cables)    |

⭐ = SAA priority layer
