# Packets and encapsulation

Encapsulation is the mechanism that makes both the OSI and TCP/IP models work
in practice. Each layer wraps the data from the layer above in its own header,
adding only the information that layer needs to do its job. The reverse process
— stripping headers on the receiving end — is called decapsulation.

---

## Core definitions

### Packet

A unit of data at layer 3 (Network). It consists of an IP header — containing
the source and destination IP addresses — wrapped around a TCP segment. Routers
read only the IP header to forward the packet hop-by-hop toward its destination.

---

### Encapsulation

The process by which each layer of the OSI or TCP/IP model wraps the data
passed down from the layer above in its own header (and in the case of layer 2,
a trailer), adding the information that layer needs to do its job. The result
is a nested structure — data inside a segment inside a packet inside a frame —
where each layer is independent and reads only its own header.

---

### Decapsulation

The reverse process on the receiving side. Each layer reads its own header,
performs its function, strips the header, and passes the remainder up to the
layer above. By the time data reaches the application layer, all headers have
been removed and the original payload is intact.

---

### PDU (Protocol Data Unit)

The name given to the unit of data at each layer:

| Layer | PDU     | Layer Identifier |
|-------|---------|------------------| 
| 7–5   | *Data*    | Application, Presentation, Session layers |
| 4     | *Segment* | Transport |
| 3     | *Packet*  | Network |
| 2     | *Frame*   | Data-Link |
| 1     | *Bit*     | Physical |

---

### FCS (Frame Check Sequence)

A checksum added as a trailer (not a header) at layer 2 by the data link layer.
The receiver recalculates the checksum on arrival — if it does not match, the
frame was corrupted in transit and is discarded. FCS is the only example of a
footer rather than a header in the stack.

---

## The encapsulation process (sender → receiver)

```
SENDER — encapsulation (down the stack)
────────────────────────────────────────────────────────────────
Layer 7  Data         HTTP request created by the browser
          │
          ▼
Layer 4  Segment      [TCP header: ports, seq number] + Data
          │
          ▼
Layer 3  Packet       [IP header: src IP, dst IP] + Segment
          │
          ▼
Layer 2  Frame        [MAC header: src MAC, dst MAC] + Packet + [FCS]
          │
          ▼
Layer 1  Bits         101101000110... transmitted as signal


RECEIVER — decapsulation (up the stack)
────────────────────────────────────────────────────────────────
Layer 1  Bits         Raw signal received, frame reconstructed
          │
          ▼
Layer 2  Frame        MAC header checked and stripped → Packet
          │
          ▼
Layer 3  Packet       IP header checked and stripped → Segment
          │
          ▼
Layer 4  Segment      TCP header checked, order verified → Data
          │
          ▼
Layer 7  Data         Original HTTP request delivered to the server
```

---

## Why encapsulation works: separation of concerns

Each layer reads only its own header and ignores everything else:

- A router at layer 3 reads the IP header only — it has no knowledge of HTTP
- The OS at layer 4 reads the TCP header only — it does not care about MAC addresses
- The web application at layer 7 receives only the HTTP request — it has no
  knowledge of how the data was physically transmitted

This independence means any layer can be swapped without affecting the others.
Replacing Wi-Fi with Ethernet changes only layer 1 and 2 — layers 3, 4, and 7
are completely unaffected.

---

## Analogy

Think of encapsulation as a gift wrapped in multiple nested boxes:

- The gift itself is the data (HTTP request)
- The innermost box is labelled with which room to put it in — TCP header (port number)
- The shipping box is labelled with the full home address — IP header (destination IP)
- The courier bag is labelled with just the next depot — MAC header (next hop only)
- The courier van physically carries it — layer 1 (physical medium)

Each handler reads only their label and passes it on. The depot does not open
the shipping box. The courier does not care what the gift is. Decapsulation is
the receiver opening each box in reverse order until the original gift is
revealed.
